Preparativos / ayuda antes del evento


Volver al evento


Evento
El Día del HTML es una juntada para hacer cosas en (y con) la web, inspirada en HTML.energy: páginas personales, experiments, poemas, collages, prototipos, zines, archivos raros, lo que pinte.
No hace falta traer compu si no vas a trabajar con compu: podés venir a mirar, conversar, ayudar, o armar algo en papel y después pasarlo a HTML (o dejarlo como obra en sí).
Experiencia en HTML
No hace falta saber: nos vamos a ayudar entre todos. Si querés llegar con una mínima base, acá van recursos muy simples (y gratis):
MDN: empezar con HTML
MDN: primeros pasos con CSS
MDN: primeros pasos con JavaScript
freeCodeCamp: Responsive Web Design
freeCodeCamp: JavaScript
javascript.info (inglés): guía completa
Si ya sabés un poco, mejor todavía: traé tus trucos, snippets y recursos para compartir.
Servidor
Un “hosting” (o servidor) es el lugar donde subís tus archivos (por ejemplo index.html, imágenes, CSS) para que tu sitio quede online con una URL.
Si no tenés uno para usar en el evento, recomendamos crearte una cuenta en alguno de estos hostings para sitios estáticos:
Neocities
Te da un sitio y un panel web para subir archivos o editar tu HTML desde el navegador. En general, tu home va a ser index.html en la raíz del sitio.

- Crear cuenta / entrar
- Subís una carpeta o archivos sueltos (HTML/CSS/JS/imagenes)
- Publica con una URL del estilo tusitio.neocities.org
Nekoweb
Funciona parecido: sitio estático + administrador de archivos para subir y organizar tu web.

- Crear cuenta / entrar
- Subís tus archivos y apuntás a index.html como página principal
Si preferís, también sirve cualquier otra opción de hosting (GitHub Pages, Netlify, tu propio servidor, etc.).
Tip extra
Si venís sin idea, podés arrancar con una página mínima: un título, un párrafo, un link y una imagen. Con eso ya estás “haciendo web”.
